# Licensing and provenance policy

LogiControl is distributed under GPL-3.0-or-later.

Permissively licensed source may be incorporated if its notice is retained in
the source and `THIRD_PARTY_NOTICES.md`. GPL-compatible derivative source must
retain its copyright and SPDX provenance.

Protocol facts and interoperability behavior should be expressed with project
terminology and independently written tests. This is not a mechanism for
removing attribution: `docs/protocol-sources.md` must identify the behavioral
reference even when no source is copied.

Do not directly copy from `lg4ff_userspace` without resolving whether the
project's grant is GPL-2.0-only. GPL-2.0-only code cannot be combined into this
GPL-3.0-or-later work merely because both are GPL-family licenses.
